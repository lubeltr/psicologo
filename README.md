# Simón Martínez · Landing

Sitio estático sin dependencias. `index.html` incluye CSS, JavaScript e imágenes para abrir o compartir como un único archivo. Los archivos `styles.css`, `script.js` y `assets/` conservan las fuentes editables; si se modifican, actualizar también el contenido incluido en el index.

Para servirlo: `python3 -m http.server 3001 --bind 0.0.0.0` desde esta carpeta.

Las imágenes de la persona y el consultorio fueron generadas para esta maqueta. No representan a Simón ni su consultorio real y están marcadas como ilustrativas. Las reseñas son ficticias y están identificadas como ejemplos. Reemplazar por contenido real antes de publicar.

Diseño validado a 320, 360, 390, 430, 640, 768, 1024 y 1440 píxeles. Se conserva el menú de tres barras solo en celular y se respeta la preferencia de movimiento reducido.
